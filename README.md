# Base10 to BaseX converter

Simple go webserver that takes a base 10 number and converts it to another base. 

purpose was just to learn go some more, its pretty fun

## Running

```bash
# clone 
git clone https://github.com/Betim-Hodza/base_converter_go.git
cd base_converter_go 
go run main.go
```

it makes a http web server on port 2047

http://localhost:2047
